# MiceGard 비공식 한국어 패치

이 패치는 팬이 비상업적으로 제작·배포하는 비공식 번역 패치입니다. MiceGard 개발사·배급사·Steam의 공식 제품이 아니며, 이들로부터 승인받거나 지원받지 않습니다. 게임은 별도로 정식 설치해야 합니다.

## 처음 설치하는 분들을 위한 빠른 안내

GitHub를 처음 사용하더라도 아래 순서대로 진행하면 됩니다.

### 1. 한글패치 다운로드

GitHub 저장소의 **Releases** 페이지에서 최신 버전을 찾습니다.

Release 페이지 아래쪽의 **Assets**를 펼친 뒤, 이름이 다음과 비슷한 한글패치 ZIP 파일을 다운로드하세요.

```text
MiceGard_한글패치_build_1.0.zip
```

> **주의:** GitHub가 자동으로 보여 주는 `Source code (zip)` 또는 `Source code (tar.gz)`는 한글패치 설치 파일이 아닙니다.  
> 반드시 Release의 **Assets**에 첨부된 `MiceGard_한글패치_...zip` 파일을 받으세요.

브라우저에 ZIP 파일이 위험할 수 있다는 안내가 표시되더라도, 다운로드한 파일 이름이 이 저장소의 Release에 첨부된 한글패치 ZIP과 같은지 먼저 확인하세요.

### 2. ZIP 파일 압축 풀기

다운로드한 ZIP 파일을 마우스 오른쪽 버튼으로 클릭한 뒤:

**모두 압축 풀기...**

를 선택합니다.

압축을 푼 폴더 안에는 `install.bat`, `uninstall.bat`, `payload` 폴더 등이 있어야 합니다.

> ZIP 파일 안에서 `install.bat`을 바로 실행하지 마세요.  
> 반드시 **먼저 모든 파일을 압축 해제한 뒤** 실행해야 합니다.

### 3. MiceGard를 완전히 종료하기

패치를 설치하기 전에 MiceGard가 실행 중이라면 종료하세요.

가능하면 Steam에서도 게임이 **실행 중** 상태가 아닌지 확인한 뒤 설치하세요.

### 4. `install.bat` 실행

압축을 푼 폴더 안의:

```text
install.bat
```

을 더블 클릭합니다.

Steam 기본 설치 위치에 MiceGard가 설치되어 있다면 설치 프로그램이 자동으로 게임 폴더를 찾습니다.

자동으로 찾지 못하면 MiceGard 설치 폴더를 입력하면 됩니다.

게임 설치 폴더를 찾는 가장 쉬운 방법:

1. Steam에서 **라이브러리**를 엽니다.
2. `MiceGard`를 마우스 오른쪽 버튼으로 클릭합니다.
3. **관리 → 로컬 파일 탐색** 또는 **속성 → 설치된 파일 → 찾아보기**를 선택합니다.
4. 열린 `MiceGard` 폴더의 경로를 설치 프로그램에 입력합니다.

또는 열린 MiceGard 게임 폴더 자체를 `install.bat` 위로 끌어다 놓아도 됩니다.

### 5. 설치 완료 후 게임에서 한국어 선택

설치가 정상적으로 끝나면 Steam에서 MiceGard를 실행합니다.

메인 메뉴에서:

**Settings(설정) → Language(언어)**

로 이동한 뒤 **태극기 아이콘**을 선택하세요.

이미 태극기 아이콘이 선택되어 있다면 그대로 플레이하면 됩니다.

### 설치가 정상적으로 되었는지 확인하는 방법

다음 항목이 확인되면 정상 설치된 것입니다.

- 설치 프로그램이 오류 없이 완료됨
- MiceGard가 정상적으로 실행됨
- 설정의 언어 항목에 태극기 아이콘이 있음
- 메뉴와 대사가 한국어로 표시됨

## 설치 중 문제가 생기면

### `install.bat`을 실행했는데 창이 바로 닫히거나 오류가 표시됩니다

먼저 다음을 확인하세요.

1. 게임이 완전히 종료되어 있는지 확인합니다.
2. ZIP 파일을 전부 압축 해제했는지 확인합니다.
3. `install.bat`, `payload` 폴더 등 ZIP 안의 파일들이 같은 폴더 구조로 존재하는지 확인합니다.
4. Steam의 MiceGard 파일이 원본 상태인지 확인합니다.

다른 모드나 이전 한글패치가 적용된 `data.win`에는 이 패치가 설치되지 않을 수 있습니다.

### 게임 파일이 원본이 아니라는 메시지가 나옵니다

Steam에서 원본 파일을 복구하세요.

1. Steam 라이브러리에서 `MiceGard`를 마우스 오른쪽 버튼으로 클릭합니다.
2. **속성**을 선택합니다.
3. **설치된 파일**을 선택합니다.
4. **게임 파일 무결성 검사**를 실행합니다.
5. 검사가 끝나면 다시 한글패치를 설치합니다.

> Steam 무결성 검사를 실행하면 기존 한글패치가 제거될 수 있습니다.

### 파일을 쓸 권한이 없다고 나옵니다

`install.bat`을 마우스 오른쪽 버튼으로 클릭한 뒤:

**관리자 권한으로 실행**

을 선택해서 다시 시도하세요.

일반적으로 관리자 권한은 필요하지 않지만, Steam 설치 위치나 Windows 권한 설정에 따라 필요할 수 있습니다.

### Windows에서 실행 경고가 표시됩니다

BAT/PowerShell 설치 파일은 Windows에서 경고가 표시될 수 있습니다.

이 패치는 `install.bat`에서 포함된 PowerShell 설치 스크립트를 실행해 `data.win`에 패치를 적용합니다.  
출처가 이 GitHub 저장소의 공식 Release인지 다시 확인한 뒤 진행하세요.

불안하다면 설치 전에 ZIP 내부의 `install.bat`, PowerShell 스크립트 및 README 내용을 직접 확인할 수 있습니다.

## 한글패치 삭제 방법 — 초보자용

한글패치를 삭제하고 원래 게임으로 돌아가려면:

1. MiceGard를 종료합니다.
2. 한글패치를 압축 해제했던 폴더를 엽니다.
3. `uninstall.bat`을 더블 클릭합니다.
4. 설치 프로그램의 안내에 따라 MiceGard 폴더를 지정합니다.
5. 백업된 원본 `data.win`이 복원됩니다.
6. Steam에서 게임을 실행해 정상적으로 돌아왔는지 확인합니다.

한글패치를 설치할 때 생성된:

```text
MiceGard_KO_Backup
```

폴더에는 원본 `data.win`이 보관됩니다.

게임이 정상적으로 원상 복구된 것을 확인한 뒤에는 이 백업 폴더를 직접 삭제해도 됩니다.

백업 파일이 없거나 게임 업데이트로 원본 버전이 달라진 경우에는 Steam의 **게임 파일 무결성 검사**로 원래 게임 파일을 복구하면 됩니다.

## 자주 묻는 질문

### Q. 게임을 다시 설치해야 하나요?

아니요. 정상적인 Steam판 MiceGard가 설치되어 있으면 됩니다.

### Q. 인터넷이 필요한가요?

한글패치 ZIP을 다운로드한 뒤에는 설치 과정에서 별도의 인터넷 연결이나 추가 프로그램이 필요하지 않습니다.

### Q. xdelta나 PowerShell을 따로 설치해야 하나요?

아니요. 필요한 `xdelta3.exe`는 패치에 포함되어 있고, PowerShell은 Windows의 기본 구성 요소를 사용합니다.

### Q. 세이브 파일이 지워지나요?

아니요. 이 패치는 게임 설치 폴더의 `data.win`만 수정하며 세이브 파일은 수정하거나 삭제하지 않습니다.

### Q. 게임이 업데이트되면 어떻게 되나요?

게임 업데이트로 `data.win`이 바뀌면 현재 패치가 설치되지 않거나 기존 패치가 제거될 수 있습니다.

이 경우 이 GitHub 저장소의 **Releases**에서 새 게임 버전에 대응하는 최신 한글패치가 있는지 확인하세요.

### Q. 한글패치를 설치한 뒤 Steam 무결성 검사를 해도 되나요?

가능하지만 Steam 무결성 검사는 수정된 `data.win`을 원본으로 되돌릴 수 있으므로 한글패치가 제거될 수 있습니다.  
그 경우 무결성 검사가 끝난 뒤 한글패치를 다시 설치하세요.

### Q. 문제가 생겼을 때 무엇을 알려줘야 하나요?

오류를 제보할 때 다음 정보를 함께 적어 주세요.

- 사용한 한글패치 ZIP 파일 이름
- 게임 화면에 표시되는 버전
- 문제가 발생한 화면 또는 대사
- 설치 프로그램의 오류 메시지
- 가능하면 문제 화면의 스크린샷

세이브 파일이나 게임 원본 파일을 보내지는 않아도 됩니다.

## 대응 버전

- Windows용 Steam MiceGard (App ID 2430660), Steam 빌드 `13350993`, 게임 화면의 버전 `v1.1`
- 설치 프로그램은 게임 폴더의 원본 `data.win` SHA-256 `B1072EADF6734DD273001999DF8911E76BCE8BE2752FC591A185EBB91FD07675`를 검사합니다. 다른 버전이나 다른 모드가 적용된 파일에는 설치하지 않습니다.
- 설치 후 `data.win` SHA-256: `91AFDAE5E66B160A24CF180C31D7FF495FC8D4DA243233B17771BDF2133C31DE`
- ZIP에는 게임 원본, 게임 실행 파일, 별도의 폰트 파일을 넣지 않았습니다. 정식 게임이 설치된 PC에서는 이 ZIP만 내려받으면 패치할 수 있습니다. 인터넷이나 추가 도구는 필요하지 않습니다.

## 설치

1. 게임을 종료하고 ZIP의 **모든 파일**을 한 폴더에 압축 해제합니다. ZIP 안에서 바로 실행하지 마세요.
2. `install.bat`을 실행합니다. Steam 기본 설치 위치를 찾지 못하면 게임 설치 폴더를 입력합니다. 또는 게임 설치 폴더를 `install.bat` 위에 끌어다 놓아도 됩니다.
3. 프로그램이 원본 버전, 패치 파일 및 결과물을 검사합니다. 설치 직전 게임 폴더의 `MiceGard_KO_Backup\data.win`에 원본을 보관합니다.
4. 게임을 실행하고 메인 메뉴의 설정 → 언어에서 태극기 아이콘을 선택합니다. 이미 한국어로 설정돼 있다면 그대로 사용하세요.

설치 대상은 게임 설치 폴더의 `data.win` 한 파일입니다. 세이브 파일은 수정하거나 삭제하지 않습니다. 설치 중 오류가 나오면 메시지를 확인하고 게임을 종료했는지, Steam 게임 파일이 원본인지 확인하세요. Steam에서 **속성 → 설치된 파일 → 게임 파일 무결성 검사**로 원본을 복구한 후 다시 설치할 수 있습니다.

설치 폴더에 파일을 쓸 권한이 없다는 오류가 나오면 `install.bat`을 관리자 권한으로 실행하세요.

## 삭제

1. 게임을 종료하고 압축을 풀었던 폴더의 `uninstall.bat`을 실행합니다. 필요하면 설치 때와 같은 게임 설치 폴더를 입력하거나 끌어다 놓습니다.
2. `MiceGard_KO_Backup\data.win`의 원본이 검증된 뒤 게임 파일로 복원됩니다. 복원 후 백업 폴더는 안전을 위해 남겨 둡니다. 게임이 정상 실행되는 것을 확인한 다음 직접 삭제할 수 있습니다.
3. ZIP의 압축 해제 폴더는 더 이상 필요하지 않으면 삭제할 수 있습니다. 패치 파일은 세이브 파일에 영향을 주지 않습니다.

백업이 없거나 게임이 업데이트됐다면 삭제 프로그램은 파일을 덮어쓰지 않습니다. Steam의 게임 파일 무결성 검사로 원본을 복구하세요.

## 알려진 사항

- 이 배포본은 위 Steam 빌드의 원본 파일에만 대응합니다. 게임 업데이트나 Steam 무결성 검사는 패치를 제거할 수 있습니다.
- 번역 자료 중 8개 항목은 원문 유지로 지정돼 영어가 남습니다.
- 메뉴, 언어 전환, 주요 대사 및 이미지 교체를 검사했지만 게임 전체를 처음부터 끝까지 완주하며 모든 문장과 화면을 확인하지는 못했습니다. 긴 대사 줄바꿈이나 드문 화면에서 잘림·표시 문제가 있을 수 있습니다.
- 이 배포본은 Windows에서 사용하는 BAT/PowerShell 설치 파일을 포함합니다. PowerShell은 Windows 기본 구성 요소입니다. 관리자 권한은 일반적으로 필요하지 않지만, Steam 설치 폴더의 쓰기 권한을 요구할 수 있습니다.

오류를 보고할 때는 게임 버전, 문제가 난 화면, 오류 메시지와 사용한 ZIP 이름을 알려 주세요. 원본 세이브 파일은 보내지 않아도 됩니다.

## 포함 파일과 라이선스

- `payload/MiceGard_Korean_Full.xdelta`: 정식 게임의 원본 `data.win`을 사용해 한국어판 파일을 만드는 차분 패치입니다.
- `payload/xdelta3.exe`: Xdelta 3.2.0 디코더. Apache License 2.0. 배포 바이너리에 정적으로 연결된 liblzma(XZ Utils)는 0BSD, BLAKE3는 Apache License 2.0 선택 라이선스로 고지합니다.
- KCC간판체(KCC-Ganpan)를 사용해 만든 한글 글리프 이미지가 패치 결과물에 포함됩니다. 원본 TTF는 배포하지 않습니다. 글꼴 저작권은 한국저작권위원회에 있으며 SIL Open Font License 1.1이 적용됩니다.
- 자세한 저작권 표시, 원문 라이선스와 출처: `LICENSES/THIRD_PARTY.md` 및 같은 폴더의 라이선스 파일.

패치 자체의 비상업적 팬 배포 방침은 위 폰트·도구의 별도 오픈소스 라이선스에 따른 권리를 제한하지 않습니다. 이 ZIP에 게임 원본 데이터는 들어 있지 않으며, 게임 및 관련 상표의 권리는 해당 권리자에게 있습니다.
